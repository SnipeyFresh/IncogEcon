# Licensing

No software license was selected automatically for this package.

That choice affects what other people are legally allowed to do with the source after you publish it. Before making the GitHub repository public, choose a license intentionally and place its standard text in a root-level file named `LICENSE`.

Common choices include:

- **MIT** - permissive; allows reuse/modification/distribution with copyright/license notice.
- **Apache-2.0** - permissive plus explicit patent terms.
- **GPL-3.0** - copyleft; redistributed derivative works must remain under GPL terms.
- **No license** - by default others generally do not receive permission to copy, modify, or redistribute the code beyond rights provided by the hosting platform/law.

This document is not legal advice; choose the license based on how you want the project used.
