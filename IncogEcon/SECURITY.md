# Security Policy

Economy plugins can expose duplication, escrow, or balance-loss bugs if transaction paths are changed incorrectly.

For security-sensitive reports (item duplication, money duplication, unauthorized shop access, escrow loss, permission bypass), avoid publishing a detailed exploit in a public issue until the maintainer has had a chance to review it.

When reporting, include:

- IncogEcon version
- Paper/Purpur build
- Java version
- Relevant economy/Vault provider
- Geyser/Floodgate versions if Bedrock is involved
- Exact reproduction steps
- Relevant logs

A repository-specific private contact/security-advisory channel should be configured after the GitHub repository is created.
